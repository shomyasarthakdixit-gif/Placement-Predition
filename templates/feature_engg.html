Mathematical Transformations

A high-level overview of the advanced mathematical transformations applied to the 50,000 student records before they are fed into our Machine Learning pipelines.

Scaling & Standardization

Numeric features are scaled using StandardScaler (for Gaussian data like CGPA) and RobustScaler (to handle extreme outliers) so distance-based models evaluate them equally.

Go to Scaling Dashboard

Target Encoding

Applied to high-cardinality features like City and Specialisation. We mathematically replace the category string with the historical average Placement Probability of that category!

Explore Encodings

OHE & Ordinal Encoding

One-Hot Encoding expands low-cardinality nominals (Gender, Hostel) into binary vectors. Ordinal Encoding preserves the mathematical hierarchy of CollegeTier (1 > 2 > 3).

Explore Encodings

Embedding / Hashing

Applied to Stream. We utilize a highly efficient HashingEncoder to map strings into a dense n-dimensional embedding vector, solving the curse of dimensionality without deep learning!
